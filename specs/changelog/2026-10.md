# Changelog — 2026-10

> Append-only; one line per change, newest last.

- 2026-10-01 — **Epic 0011 opened (D153)**: lane P's twelve asks of 2026-10-01 are carried in this
  repository rather than `shadow`, because the product ships on 0.36.0 today and the native harness
  is two to three weeks from usable. Phases numbered from 59 so no transferred ID (46–58) is
  reused; a bounded bridge, with D142–D152 and the native destination unchanged.
- 2026-10-01 — **The reply to lane P**: three of the twelve are already built and need no kit
  change — `StoreSkills` makes their database a skill source, `SkillComponents` already delivers
  skills to a governed CLI as relay tools, and `mint_skill` already proposes on the sink. One real
  gap found and made the first item: `codex exec` maps no `system`/`append_system` flag, so a
  product's instructions reach Claude Code and not Codex — named on `thread.unmapped_behaviour`,
  but not delivered.
- 2026-10-01 — **ENH-051 closed (Epic 0011 Q1): a CLI with no system-prompt flag is told who to be
  in the turn.** `Dialect.instructions_in_prompt` (default false) plus one pure kernel derivation
  frames a mode's instructions as an `<instructions>` block on the first turn only, never for a
  field the dialect maps a flag for. `codex.toml` switches it on; `unmapped_behaviour` stops naming
  what is now delivered and still names `temperature`. Measured live on claude 2.1.284 with
  `--system-prompt` removed from its record, so the fold was the only way in; the Codex legs skip
  unmeasured, because a ChatGPT-account Codex on this laptop cannot run any model.
- 2026-10-01 — **Phase 59: a change is legible on the record (ENH-044, D154–D156).** `write_file`,
  `edit_file` and `delete_file` carry a bounded unified diff with exact line counts, plus
  `created`/`deleted`/`before_unreadable` markers, so a host shows what an agent changed without
  reading the environment's root — which raced the agent and could not work at all for a contained
  or remote environment. `move_file` deliberately carries none: no content delta, and `from`/`to`
  are the whole story. Capturing a change never fails the write (D155). And the kit now keeps a
  run's proposals only when nobody else is listening (D156) — a host that passes its own `sink=`
  gets them and the kit's store stays empty, which is what lane P asked for; with no sink it still
  keeps, because that is the only way a minted skill survives a restart. Gate: 1936 passed,
  mypy 483 files, sixteen mutations biting.
- 2026-10-01 — **Phase 60: the write-class toolset completes (ENH-042 closed, D157–D160).**
  `apply_patch` changes regions across many files as one act, every edit validated before any file
  is written, so a refused patch leaves the workspace exactly as it was; its vocabulary and its
  validation are `edit_file`'s, not a diff parser. Beside it a background shell —
  `run_background`, `job_output`, `kill_job` — where the **environment owns the job and `close()`
  ends every one** (D157): D35 kept one level up, the move BUG-019 forced for provider sessions.
  A mutation pass caught that the sandbox wrap and the narrow environment on the background path
  were untested claims; both are tested now. Gate: 1957 passed, mypy 485 files, eleven mutations
  biting.
- 2026-10-01 — **Phase 61: undo, and an agent's own workspace (ENH-043, D161–D165).** A new
  `WorkspaceHistoryPort` with a shipped git adapter, attached wherever a local root has a `.git` —
  a linked worktree included. A restore is itself an act: `delete`-class, irreversible, and `ask`
  stops a person before an undo, because an undo that bypasses governance is a hole. When to
  snapshot stays the product's policy. A snapshot holds what git would track, so ignored files are
  neither deleted nor resurrected. **None of it touches the product's git state** — a scratch index
  into a parentless commit under `refs/shadow-hdk/snapshots/*`, never HEAD, a branch, the index or
  the stash. Beside it, host-side worktrees so several agents work in parallel, each on a
  `shadow-hdk/<name>` branch it can open a pull request from, with a developer's own worktrees
  unreachable. Gate: 1986 passed, mypy 490 files, eighteen mutations biting.
