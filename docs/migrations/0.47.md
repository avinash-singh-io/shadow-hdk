# 0.47.0 — agent descriptions for the chooser

One contract addition, H11-D, so a minor and Pins row (D9). Protocol 3 unchanged. Publish the
frozen 0.45.0 and 0.46.0 checkpoints first; this candidate's only new item is D.

An agent row can carry an optional `description` alongside its `name` and `system`. The existing
`agents/list` reply returns that text for a person's chooser. `system` remains the role prompt
sent to the agent; presentation text never replaces it.

```toml
name = "reviewer"
system = "Review the proposal against the team's procedure."
description = "Review a proposal"
```

Absent or null retains the current first-line derivation from `system`. An explicitly empty
description remains empty, so absence and an intentional blank are distinct. Existing callers
of agents/list need no wire-shape change. H6–H8 remain separate source-confirmed fixes.

D190: a coding tool, a support desk and a research assistant would each use human-readable
agent descriptions. This is adapter presentation data; no policy or tool meaning enters core
or runtime. D184's migration table now records this built contract.
