# 0.48.0 — workbench corrections and optional components

**Unreleased checkpoint; paused by owner.** No merge, tag or publication is authorized.
Browser replacement and Codex catalogue verification remain pending; consult Phase 67 tasks.

This minor release adds image observations, owner-scoped resource lifetime and a CLI bootstrap
option. The wire protocol remains 3. Empty image collections are omitted from old payloads.
Pydantic 2.12 or later is now required.

- Socket-offered CLI tools honour `Behaviour.tools_offered`, including after a mode switch.
  Products can remove their narrowing wrappers after validating this release with their host.
- Worktree creation accepts an optional host branch name. The default name is retained. Creation
  ownership is recorded by checkout identity; removal refuses a manually recreated checkout
  even when its path and branch match an earlier one.
- Glob and grep use Git's tracked-file and standard ignore semantics. Tracked files remain
  searchable even if a later ignore rule matches them. Non-Git roots honour nested `.gitignore`
  patterns. Traversal has no 50,000-file cutoff; result limits remain bounded and reported.
- History reuses a private Git index and restores only the paths that differ. The person's HEAD,
  index and stash are preserved, as are ignored dependencies. It still checks file metadata to
  capture external edits; a checkpoint is not constant time on arbitrary repositories.

Install `shadow-hdk[browser]` and register [BrowserComponents](../browser.md) when needed. The
direct engine is local Playwright with a pinned isolated mitmproxy gateway. Binaries provision
on first use with activity messages. Profiles are isolated, headless and scoped to their owner.
The host supplies exact allowed origins; localhost is the default. Every action has ordinary
effects and approval inputs. Screenshots are native image observations.

Install `shadow-hdk[workbench]` for [HostDoor and WorkbenchComponents](../workbench.md). Existing
background commands gain independent host output cursors and metadata. Optional local listener
inspection reports verified TCP addresses; output URLs remain unverified hints. JUnit reports
provide counts, failing names and output. Direct command/file access uses the person's supplied
environment, without an agent. Interactive PTY sessions remain future work.

`Completed.images` and `Message.images` default to empty tuples. Tool images reach the model,
MCP and the wire. LangChain projects an associated image carrier after the full text tool-result
batch to preserve native chat protocol ordering.

Components may implement `release_run(resource_scope)`. Low-level runs release their default
scope when they end and retain it while parked. A host setting `RunOptions.resource_scope` owns
teardown; Conversation/Thread preserve their scope across turns and approvals and release it
on close. Aliases release once, all ports are attempted after a failure, and close settles before
delivering cancellation. Images and scope IDs serialize; live browser processes do not survive
a host restart.

Wire hosts advertise `run_resources: true` in `initialize` to enable resource callbacks. Older
hosts receive none. New hosts must report real teardown failures. TypeScript `tool()` accepts
`releaseRun`; raw component owners use `onReleaseRun`; invocations receive `resource_scope`.
Use the updated client/runtime together when hosting resources across the wire.

The governed Codex provider now disables native world tools and boots in a private directory
so startup instructions/skills cannot read the component repository. Only injected kit file and
shell operations act on that repository, with ordinary governance and audit. Measured on Codex
CLI 0.154.0 on gpt-5.4, gpt-6-astra and gpt-6-sol, including resume. Catalogue mutation/edge
verification and final acceptance remain unfinished. Unknown explicit switches fail visibly. Uninjected CLI use keeps
its normal configuration/directory. Authentication/session storage is retained in CODEX_HOME.
This is tool governance, not OS process confinement; re-run the SDK catalogue gate when updating
the CLI. Its built-in MCP resource discovery remains, but the kit relay exposes no file resources.
