# Migrating from 0.29.1 to 0.30

> This describes the v0.30 contract being assembled by Epic 0008. It is not a release notice;
> v0.30.0 ships only after Phases 31–33 pass their combined gate.

Phase 31 adds an evidence-backed execution selection without changing the default behavior of an
existing in-process caller. If no requirements are supplied, construction continues with an empty
requirement set. A production host should opt in explicitly:

```python
from shadow_hdk.kernel import (
    EnvironmentRequirements,
    ExecutionRequirements,
    ProviderRequirements,
)
from shadow_hdk.serve import Harness

requirements = ExecutionRequirements(
    provider=ProviderRequirements(
        tool_path="controlled",
        session="resumable",
        streaming="live",
        usage_tokens=True,
    ),
    environment=EnvironmentRequirements(
        writes_within="workspace",
        network="denied",
        proven=True,
    ),
)
harness = Harness("./work", requirements=requirements)
```

An incompatible construction raises `IncompatibleCapabilities`. Its `compatibility.mismatches`
contains every gap in stable provider-then-environment order, including the available value and its
evidence. Do not convert `unknown` to a permissive default in application code; either relax the
host requirement deliberately or improve the adapter's evidence.

For a handed `AgentPort`, also hand `provider_capabilities=ProviderCapabilities(...)`. If omitted,
all provider axes are unknown. `LocalEnvironment.open` and `SandboxEnvironment.open` accept an
`EnvironmentRequirements` and expose their effective `capabilities`.

## Wire migration

The wire protocol moves from `1` to `2`; a version-1 client is refused during `initialize` instead
of being allowed to miss the new selection meaning. Regenerate or upgrade generated clients before
connecting.

- `thread/start` accepts `requirements` and returns `capabilities`.
- `thread/resume` returns a freshly checked `capabilities` selection.
- `providers/list` returns detection and provider capability evidence.
- `capabilities/check` probes a candidate without opening an agent or thread.
- incompatibility is `capability_mismatch`, with the complete mismatch list.
- persisted `ThreadRecord.version` is `3` and includes `requirements`; existing records are loaded
  through the normal versioned migration path.

The capability matrix in the README is a summary. The provider TOML records are the source for
per-axis evidence and measurement dates; environment facts come from the effective isolation and
mode, never from provider marketing or a wrapper's name.
