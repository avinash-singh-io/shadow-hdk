# Migrating from 0.29.1 to 0.30

> This describes the v0.30 contract being assembled by Epic 0008. It is not a release notice;
> v0.30.0 ships only after Phases 31–33 pass their combined gate.

Phase 31 adds an evidence-backed execution selection without changing the default behavior of an
existing in-process caller. If no requirements are supplied, construction continues with an empty
requirement set. A production host should opt in explicitly:

```python
from shadow_hdk.kernel import (
    EnvironmentRequirements,
    ExecutionRequirements,
    ProviderRequirements,
)
from shadow_hdk.serve import Harness

requirements = ExecutionRequirements(
    provider=ProviderRequirements(
        tool_path="controlled",
        session="resumable",
        streaming="live",
        usage_tokens=True,
    ),
    environment=EnvironmentRequirements(
        writes_within="workspace",
        network="denied",
        proven=True,
    ),
)
harness = Harness("./work", requirements=requirements)
```

An incompatible construction raises `IncompatibleCapabilities`. Its `compatibility.mismatches`
contains every gap in stable provider-then-environment order, including the available value and its
evidence. Do not convert `unknown` to a permissive default in application code; either relax the
host requirement deliberately or improve the adapter's evidence.

For a handed `AgentPort`, also hand `provider_capabilities=ProviderCapabilities(...)`. If omitted,
all provider axes are unknown. `LocalEnvironment.open` and `SandboxEnvironment.open` accept an
`EnvironmentRequirements` and expose their effective `capabilities`.

## Wire migration

The wire protocol moves from `1` to `2`; a version-1 client is refused during `initialize` instead
of being allowed to miss the new selection meaning. Regenerate or upgrade generated clients before
connecting.

- `thread/start` accepts `requirements` and returns `capabilities`.
- `thread/resume` returns a freshly checked `capabilities` selection.
- `providers/list` returns detection and provider capability evidence.
- `capabilities/check` probes a candidate without opening an agent or thread.
- incompatibility is `capability_mismatch`, with the complete mismatch list.
- persisted `ThreadRecord.version` is `3` and includes `requirements`; existing records are loaded
  through the normal versioned migration path.

The capability matrix in the README is a summary. The provider TOML records are the source for
per-axis evidence and measurement dates; environment facts come from the effective isolation and
mode, never from provider marketing or a wrapper's name.

## One agent surface

Phase 32 removes the product-level split between a model API and an agent CLI. Hand either an
`AgentPort` or a `ModelPort` to the existing host entry points; `ModelAgent` adapts the latter below
the same `Thread`, capability selection, tool source, lease, parking, interruption and item stream:

```python
from shadow_hdk.adapters.agent import ModelAgent, single
from shadow_hdk.runtime.threads import Thread

agent = ModelAgent(model=my_model_port, pattern=single)
thread = await Thread.open(agent=agent, ports=ports, store=store, root=".", lease=lease)
```

`Harness`, `ServeHost` and `a_thread` also accept `model=` directly. Supplying both `agent=` and
`model=` is an error; it is one choice behind one surface, not two competing lifecycles. Model
usage that is not reported remains unknown and unmetered rather than being presented as zero.

## Items and reconnectable streams

`Item.inputs` now contains the JSON value handed to the component. The fold copies canonical JSON
up to and including 64 KiB. Above that bound it emits an explicit omission marker containing the
encoded byte count; consumers must not treat the marker as the original input. The authoritative
`Invoked` event remains unchanged and retains the complete value.

`shadow_hdk.runtime.StreamSession` is the transport-independent reconnect state machine used by
HTTP/SSE: monotone durable frame ids, a bounded replay window, one attachment, a typed expired
cursor, and grace expiry under an injected clock. HTTP streams send an ephemeral heartbeat comment
after 15 seconds idle; heartbeats have no id and enter neither replay nor the runtime record.

The TypeScript client defaults `silenceSeconds` to 45. If no bytes arrive in that interval, it
cancels the silent body and reattaches with the last event id. Set `silenceSeconds: 0` only when a
surrounding transport already provides equivalent liveness detection.

## HTTP bearer sources

For non-loopback HTTP, prefer a private token file or the environment; production deployments no
longer need to place the bearer in process arguments:

```sh
shadow-hdk serve harness.toml --http --token-file /run/secrets/shadow-hdk-token
# or
SHADOW_HDK_TOKEN='...' shadow-hdk serve harness.toml --http
```

Precedence is `--token-file`, then `SHADOW_HDK_TOKEN`, then the legacy `--token` flag. The flag is
retained for local development only. A token file must be one UTF-8 line, a regular non-symlink
owned by the current user, no larger than 16 KiB, with group/other permissions denied. Errors never
include the bearer value.
