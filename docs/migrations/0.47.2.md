# 0.47.2 — native interrupt preserves the next turn

H7 / BUG-239 repairs the existing native-interrupt contract; patch, no Pins row (D9).
Protocol 3 unchanged. Publish the frozen 0.47.1 candidate first.

Claude Code's shipped JSONL dialect now sends its native interrupt control request. A cancelled
reader retains the pending interrupted-turn boundary; before writing another prompt, the session
drains the old terminal frame without reporting old thinking or activity into the new run.
The process and provider session survive, and the next answer belongs to the next prompt.
Previously native interruption was advertised but sent no request, so the thread closed the CLI.

Providers with no native interrupt line keep the close/reopen fallback. No caller changes or
new public fields are required. Live measured on Claude Code 2.1.187: interruption accepted,
same process and session retained, next turn returned SECOND_OK without failure.

D190: a coding tool, a support desk and a research assistant would each use interruption that
preserves session identity and turn boundaries. Provider transport, no operation meaning in runtime.
