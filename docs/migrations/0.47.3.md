# 0.47.3 — cache usage survives the model loop

H8 / BUG-240 repairs the existing Usage contract (D141); patch, no Pins row (D9).
Protocol 3 unchanged. Publish the frozen 0.47.2 candidate first.

The key-backed model loop now initializes, accumulates and returns both cache_read_tokens and
cache_write_tokens, and the model-session adapter reconstructs them. Cache counters reach the
existing usage event, thread meter, persisted record and wire thread listing. Previously these
adapter stages dropped them, even though the runtime already accepted both counters.

Known zero stays zero. Unknown on either axis remains unknown after later known calls; a call
without usage makes the aggregate unknown. Existing Spent counters retain their lower-bound
counting semantics. No new port, public field, wire shape or caller change is required.

D190: a coding tool, a support desk and a research assistant would each use accurate model-usage
accounting. This is adapter repair, with no operation meaning or policy added to core/runtime.
